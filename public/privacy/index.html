Privacy policy

Last updated 17 November 2026

Detour is a free and open source Mac app made by ten50 (Vinkenhof 4, 6181 KL Elsloo, the Netherlands, hallo@ten50.nl). This page explains what the app and this website do with your data. Short version: Detour keeps everything on your Mac, and we don't collect anything about you.

The Detour app

What it reads

To decide where a link opens, Detour looks at the link itself and at the app you clicked it in. If you give it Full Disk Access, it also reads the profile list and browsing history of your browsers (Chrome-family browsers, Firefox and Safari) from the last 90 days. If you allow Accessibility, it can read the title of the window you clicked in.

What it stores

Detour stores its settings and a summary in ~/Library/Application Support/Detour on your Mac: your rules, choices you taught it, per site how often you visited it in each browser profile, Google file IDs you opened before, and a log of recent decisions (site, app, destination and reason, kept for 90 days). It does not store full web addresses of your history or page titles.

What it sends

Nothing, unless you turn on the automatic update check. That check is off by default. When it's on, Detour asks GitHub once a day for the latest release of Detour. The request contains the app's version number and, like any internet request, your IP address. GitHub handles that request under the GitHub privacy statement. Detour doesn't use analytics, crash reporting, accounts or advertising.

Removing your data

Quit Detour and delete ~/Library/Application Support/Detour and ~/Library/Caches/Detour. Nothing else exists anywhere, so there is nothing to request from us.

This website

detour.ten50.nl has no cookies, analytics or trackers, and loads nothing from other sites except a version check: your browser asks GitHub for the latest Detour release so the page can show the version number. Our web server, hosted in Germany, keeps standard access logs (IP address, time, requested page and browser) for security and troubleshooting, and deletes them automatically after about 8 weeks. The site is served through Cloudflare, which processes requests to deliver and protect the site.

Downloads come straight from GitHub Releases, so GitHub's privacy statement applies to them.

Your rights

Under the GDPR you can ask what we know about you, and ask us to correct or delete it. For the app the answer is: nothing, because it stays on your Mac. For the website server logs, mail hallo@ten50.nl. You can also file a complaint with the Dutch Data Protection Authority (Autoriteit Persoonsgegevens).

Changes

If this policy changes, we update this page and the date above. The source of the app is public on GitHub, so you can always check what it does.
